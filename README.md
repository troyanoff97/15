# 15 минут. — Искусство управлять временем

[Открыть CHRONOS](https://troyanoff97.github.io/15/)

Кинематографический сайт про опоздание. Таймер, фильм, музыка и центр управления прибытием работают в браузере. Местоположение не запрашивается.

## Локальный запуск

Запустите из корня проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [локальную страницу](http://127.0.0.1:8000/). Персональная ссылка принимает `q` (вопрос), `name` (имя) и `minutes` (первый интервал от 1 до 120 минут).

GitHub Pages публикует корень ветки `main`. Сборка и внешние зависимости не требуются. Сведения о медиа есть в [LICENSES.md](LICENSES.md).

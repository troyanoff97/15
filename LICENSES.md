# Медиа и зависимости

- Портрет создан на основе фотографии, приложенной заказчиком. WebP сохраняет прозрачный фон для послойной композиции. Превью использует тот же портрет. Права на исходное фото сохраняются за его правообладателем.
- `chronos-theme.mp3` — оригинальная 36-секундная синтезированная композиция, созданная для этого проекта. Сочетает тиканье, органоподобные тоны, струнные слои, синтезатор и низкочастотные удары. Заимствованные записи и музыкальные семплы не использованы.
- Шесть эффектов в `assets/sfx/` синтезированы для проекта. Их можно использовать вместе с приложением.
- Сайт использует системные шрифты. Сторонних шрифтов, библиотек, аналитики и CDN в поставке нет.
